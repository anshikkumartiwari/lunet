ESP32-S3 CAR CLUSTER - CONNECTIVITY SCREEN
==========================================

What this first build shows
---------------------------
- A minimal dark 800x480 dashboard-style UI.
- Wi-Fi state: NOT CONNECTED / CONNECTING / CONNECTED.
- When connected, it shows the network name, IP address, and RSSI.
- Bluetooth LE state: ADVERTISING / CONNECTED / UNAVAILABLE.
- The ESP32 advertises as "ESP32-Car-Cluster" with a small GATT service.
- The GT911 touch driver is initialized for future touchscreen controls, but this first screen does not need touch input.

Your existing Arduino setup
---------------------------
Keep the versions already recorded in your working configuration:
- Board: ESP32S3 Dev Module
- Arduino-ESP32 core: 3.3.13
- ESP32_Display_Panel: 1.0.0
- ESP32_IO_Expander: 1.0.1
- esp-lib-utils: 0.1.2
- Flash: 16 MB
- PSRAM: OPI PSRAM
- Upload speed / Serial Monitor: 115200

One additional library
----------------------
Install LVGL version 8.4.0 (not LVGL 9) using Arduino IDE Library Manager.
Search for "lvgl" and select version 8.4.0.

How to open
-----------
1. Extract this ZIP.
2. Open the folder "CarCluster_Connectivity".
3. Double-click CarCluster_Connectivity.ino.
4. Select ESP32S3 Dev Module and your current COM port.
5. Keep your saved board options. Do not downgrade or update the ESP32 core or display-panel libraries for this sketch.
6. Compile and upload.
7. Open Serial Monitor at 115200 baud.

Wi-Fi test (optional)
---------------------
At the top of CarCluster_Connectivity.ino, find:

  static const char *WIFI_SSID     = "";
  static const char *WIFI_PASSWORD = "";

Enter your 2.4 GHz Wi-Fi or phone-hotspot name and password between the quotes.
Upload again. The Wi-Fi card should change from NOT CONNECTED to CONNECTING and then CONNECTED. It will show the IP address and signal strength after connecting.

Bluetooth LE test
-----------------
The board starts BLE advertising automatically. On an Android phone, install/open a BLE scanner such as nRF Connect and scan for:

  ESP32-Car-Cluster

Connect to it. The Bluetooth card should change from ADVERTISING to CONNECTED. The service exposes one simple read/write characteristic. This is Bluetooth Low Energy, not Bluetooth Classic audio/pairing.

Important compatibility notes
-----------------------------
- The project includes project-local ESP32_Display_Panel 1.0.0 configuration files for the Waveshare 4.3-inch 800x480 ST7262 / GT911 / CH422G board.
- It does not overwrite any global Arduino library files.
- The LVGL display/touch adapter is kept inside the sketch and uses the same ESP32_Display_Panel Board/LCD/Touch API as the ESP32_Display_Panel 1.0.0 LVGL v8 simple-port example.
- The screen layout is generated by LVGL widgets (labels and rounded cards), not a static screenshot.
- I cannot compile against your local Windows Arduino installation from this environment. If Arduino reports a compile error, send the complete error text or a screenshot before changing library versions.
